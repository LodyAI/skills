# Lody Skills

[![skills.sh](https://skills.sh/b/LodyAI/skills)](https://skills.sh/LodyAI/skills)

Official Agent Skills for [Lody](https://github.com/LodyAI/Lody).

## Install

```bash
npx skills add LodyAI/skills
```

Or install a specific skill globally:

```bash
npx skills add LodyAI/skills --skill lody -g
npx skills add LodyAI/skills --skill lody-cli -g
```

## Available skills

- [`lody`](skills/lody/SKILL.md) — User guide, actionable in-app links, troubleshooting, and source-code reference map for Lody across desktop, web, mobile, and CLI.
- [`lody-cli`](skills/lody-cli/SKILL.md) — Drive Lody from a terminal with the `lody` CLI (sessions, schedules, automations, agent configs, Roles, MCP servers, projects, machines, the background runtime, sync/export and review rendering).
